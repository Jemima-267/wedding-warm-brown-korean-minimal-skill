# 韩系暖棕极简婚礼插画 Skill

这是一套面向婚纱照风格化重绘的中文 Skill，旨在将用户提供的婚礼照片转化为温柔、克制、轻盈的韩系婚礼纸品插画。它强调保留原照片的核心构图和人物关系，同时统一线条、减少细节，并通过大面积留白与少量低饱和色彩营造精致的暖棕色视觉风格。

## 主要特点

- 忠实保留人物姿势、相对位置、身高关系与手部互动
- 保留发型、服装、背景和花卉的主要视觉特征
- 使用稳定、接近等线宽的暖棕色线条
- 将人物五官处理为简洁、成熟的符号化造型
- 大幅简化婚纱、西装、背景及花卉细节
- 以奶油白和暖象牙白为主，辅以少量低饱和色彩
- 强调人物周围及画面上方的留白与呼吸感
- 避免写实肖像、普通照片描边、动漫或 3D 渲染效果

## 适用场景

本 Skill 适合用于制作：

- 婚礼邀请函插画
- Save the Date 配图

- 婚礼纪念卡片
- 婚礼社交媒体配图
- 韩系极简婚礼纸品视觉素材

## 使用方法

1. 下载或复制仓库中的 `SKILL.md`。
2. 在支持图片理解和图片生成的 AI 工具中加载该文件内容。
3. 上传一张清晰的婚纱照作为主要参考图。
4. 要求 AI 按照该 Skill 将照片转换为韩系暖棕极简婚礼插画。
5. 如需修改，可提出“线条更统一”“人物再简单一点”“花卉更简洁”“背景更留白”等具体要求。

建议使用全身或四分之三身照片，并确保人物动作、手部关系、服装轮廓和主要背景结构清晰可见。

## 核心视觉原则

最终画面应遵循以下方向：

- **构图忠实：** 不随意改变人物动作、站位、服装类型、花卉种类或背景结构。
- **线条统一：** 使用流畅、圆润、干净的暖棕色中细线，避免粗黑轮廓和草稿感。
- **人物极简：** 五官高度简化，但保持成年人的自然比例与优雅感。
- **服装减法：** 保留可识别的服装轮廓，删除大部分褶皱、蕾丝、刺绣及材质纹理。
- **背景克制：** 保留主要结构，去除干扰性细节，让背景服务于人物主体。
- **花卉忠实：** 简化原有花卉，而不是随机更换花型或重新设计花艺。
- **留白主导：** 以奶油白、象牙白和暖棕线稿为主，只使用少量柔和点彩。

## 输出目标

成品应像一张经过完整设计的韩系婚礼邀请函插画，而不是照片滤镜、自动描边或写实肖像。整体气质应保持：

> 温柔、干净、浪漫、克制、轻盈、现代、优雅。

## 注意事项

- 本项目提供的是创作规则与提示词，不包含图片生成模型或独立运行程序。
- 实际效果会受到参考照片质量、所用模型及模型图片编辑能力的影响。
- 请确保你拥有参考照片的使用权，并尊重照片中人物的隐私和肖像权。
- 商业使用前，请确认所使用 AI 平台的服务条款和生成内容许可范围。
